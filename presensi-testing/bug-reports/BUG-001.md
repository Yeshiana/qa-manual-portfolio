# BUG-001: Perubahan data karyawan oleh admin tidak tersimpan

| Keterangan | Detail |
|---|---|
| Aplikasi | Website Presensi Karyawan (proyek PKL, Pusjar SKTAN LAN RI) |
| Role | Admin |
| Severity | High |
| Status | Fixed |

## Langkah Reproduksi
1. Login sebagai admin
2. Buka menu data karyawan
3. Edit data salah satu karyawan
4. Klik Simpan

## Expected Result
Data karyawan terupdate dan tampil di daftar karyawan.

## Actual Result
Data tetap sama seperti sebelum diedit.

## Catatan
Bug report ini ditulis ulang dari temuan saat pengembangan dan pengujian black box, bukan dari dokumen pengujian formal. Bug sudah diperbaiki dan diuji ulang sebelum sistem diserahkan.
