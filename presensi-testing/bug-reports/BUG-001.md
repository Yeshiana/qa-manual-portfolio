# BUG-001: Perubahan data karyawan oleh admin tidak tersimpan

| Keterangan | Detail |
|---|---|
| Aplikasi | Website Presensi Karyawan |
| Role | Admin |
| Severity | High |
| Status | Fixed |

## Langkah Reproduksi
1. Login sebagai admin
2. Buka menu data karyawan
3. Edit data karyawan
4. Klik Simpan

## Expected Result
Data karyawan terupdate dan tampil di daftar.

## Actual Result
Data tetap sama seperti sebelum diedit.
