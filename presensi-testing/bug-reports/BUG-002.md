# BUG-002: Riwayat absensi di halaman admin tidak sama dengan halaman karyawan

| Keterangan | Detail |
|---|---|
| Aplikasi | Website Presensi Karyawan |
| Role | Admin dan Karyawan |
| Severity | High |
| Status | Fixed |

## Langkah Reproduksi
1. Karyawan melakukan absensi
2. Bandingkan riwayat absensi di halaman karyawan dengan halaman admin

## Expected Result
Kedua halaman menampilkan data riwayat yang sama.

## Actual Result
Data pada kedua halaman berbeda.
