# BUG-003: Batas waktu absensi masuk dan pulang tidak berlaku

| Keterangan | Detail |
|---|---|
| Aplikasi | Website Presensi Karyawan |
| Role | Karyawan |
| Severity | High |
| Status | Fixed |

## Langkah Reproduksi
1. Login sebagai karyawan
2. Coba absen masuk atau pulang di luar jam yang ditentukan

## Expected Result
Sistem menolak absensi di luar jam yang diizinkan.

## Actual Result
Absensi tetap berhasil dicatat kapan saja.
