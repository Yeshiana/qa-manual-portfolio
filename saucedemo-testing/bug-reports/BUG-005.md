# BUG-005: Kolom Last Name tidak bisa diisi dan checkout tetap bisa dilanjutkan

| Keterangan | Detail |
|---|---|
| Aplikasi | SauceDemo (saucedemo.com) |
| Akun | error_user |
| Environment | Chrome, Windows 11 |
| Severity | High |
| Status | Open |

## Langkah Reproduksi
1. Buka saucedemo.com
2. Login sebagai error_user (password: secret_sauce)
3. Tambahkan produk ke keranjang, lalu buka keranjang dan klik Checkout
4. Pada halaman "Your Information", isi First Name dan Postal Code
5. Coba isi kolom Last Name
6. Klik Continue

## Expected Result
Kolom Last Name bisa diisi. Jika dikosongkan, sistem menolak dan menampilkan pesan bahwa Last Name wajib diisi.

## Actual Result
Kolom Last Name tidak bisa diisi, tetapi sistem tetap membiarkan pengguna melanjutkan ke halaman berikutnya (validasi tidak berjalan).
