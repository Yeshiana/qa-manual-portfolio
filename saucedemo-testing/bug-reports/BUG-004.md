# BUG-004: Fitur sort hanya berfungsi untuk Name (A to Z)

| Keterangan | Detail |
|---|---|
| Aplikasi | SauceDemo (saucedemo.com) |
| Akun | problem_user |
| Environment | Chrome, Windows 11 |
| Severity | Medium |
| Status | Open |

## Langkah Reproduksi
1. Buka saucedemo.com
2. Login sebagai problem_user (password: secret_sauce)
3. Klik dropdown sort di pojok kanan atas halaman daftar produk
4. Pilih Name (Z to A), Price (low to high), dan Price (high to low) satu per satu

## Expected Result
Produk terurut sesuai opsi yang dipilih.

## Actual Result
Hanya opsi Name (A to Z) yang berfungsi. Tiga opsi lainnya tidak mengubah urutan produk.
