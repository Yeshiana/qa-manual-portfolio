# BUG-001: Gambar produk di halaman daftar tidak sesuai dengan produknya

| Keterangan | Detail |
|---|---|
| Aplikasi | SauceDemo (saucedemo.com) |
| Akun | problem_user |
| Environment | Chrome, Windows 10 |
| Severity | Medium |
| Status | Open |

## Langkah Reproduksi
1. Buka saucedemo.com
2. Login sebagai problem_user (password: secret_sauce)
3. Perhatikan gambar produk di halaman daftar produk

## Expected Result
Setiap produk menampilkan gambar yang sesuai dengan namanya.

## Actual Result
Gambar yang tampil tidak sesuai dengan produk yang seharusnya.
