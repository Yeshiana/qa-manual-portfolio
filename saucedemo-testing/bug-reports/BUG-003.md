# BUG-003: Tombol "Add to cart" di halaman detail produk tidak berfungsi

| Keterangan | Detail |
|---|---|
| Aplikasi | SauceDemo (saucedemo.com) |
| Akun | problem_user |
| Environment | Chrome, Windows 11 |
| Severity | Medium |
| Status | Open |

## Langkah Reproduksi
1. Buka saucedemo.com
2. Login sebagai problem_user (password: secret_sauce)
3. Klik salah satu produk untuk membuka halaman detail
4. Klik tombol "Add to cart"

## Expected Result
Produk masuk ke keranjang, tombol berubah menjadi "Remove", dan angka di ikon keranjang bertambah.

## Actual Result
Tombol tidak berfungsi: produk tidak masuk ke keranjang.

## Catatan
Produk masih bisa ditambahkan lewat halaman daftar produk, sehingga severity dinilai Medium.
