# BUG-006: Tombol "Finish" tidak bisa diklik pada halaman Overview

| Keterangan | Detail |
|---|---|
| Aplikasi | SauceDemo (saucedemo.com) |
| Akun | error_user |
| Environment | Chrome, Windows 11 |
| Severity | Critical |
| Status | Open |

## Langkah Reproduksi
1. Buka saucedemo.com
2. Login sebagai error_user (password: secret_sauce)
3. Tambahkan produk ke keranjang, lalu lanjutkan checkout sampai halaman "Checkout: Overview"
4. Klik tombol "Finish"

## Expected Result
Pesanan selesai dan muncul halaman konfirmasi "Thank you for your order".

## Actual Result
Tombol "Finish" tidak merespons, sehingga pesanan tidak bisa diselesaikan.

## Catatan
Tidak ada jalan pintas untuk menyelesaikan pesanan, sehingga severity dinilai Critical.
