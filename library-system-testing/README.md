# Pengujian Sistem Informasi Perpustakaan Berbasis Web

## Deskripsi
Sistem informasi manajemen perpustakaan berbasis Laravel untuk SMK Negeri 1 Bojongpicung, dikembangkan sebagai proyek akademik. Dokumen ini berisi test case hasil pengujian black box.

## Ruang Lingkup Pengujian
- Autentikasi (pendaftaran dan login)
- Pencarian buku
- Peminjaman (booking) dan batas peminjaman
- Pengembalian buku dan sanksi
- Pengelolaan data buku
- Pelaporan

## Metode
Black box testing: memberi masukan sesuai skenario, lalu membandingkan keluaran sistem dengan hasil yang diharapkan.

## Ringkasan
- Jumlah test case: 17
- Hasil: 17 Pass
- Cakupan: skenario positif dan negatif (validasi form, batas peminjaman, penolakan bukti sanksi)

## Catatan
Test case disusun dari tabel hasil pengujian pada dokumen skripsi, lalu dirapikan ke format test case standar. Hasil "Pass" menunjukkan kondisi akhir pengujian setelah perbaikan selama pengembangan.
